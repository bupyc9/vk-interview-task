# Подсчёт количества пользователей для статей

Есть публикации авторов. Нужно реализовать учёт уникальных пользователей, для каждого автора, которые открыли публикацию.

Нужно реализовать 2 метода. Первый метод логирует учёт. Второй метод возвращает количество уникальных 
пользователей за предыдущий день. Для хранения данных, реализовать in memory хранилище.
